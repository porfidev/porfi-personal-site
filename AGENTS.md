# Astro Component Guidelines

- Create reusable Astro components under `src/components`.
- Use one folder per component when it has related styles or scripts.
- Name component files with PascalCase, for example `Footer.astro`.
- Keep component-specific CSS next to the component when styles are not global.
- Prefer existing aliases such as `@components`, `@styles`, and `@scripts`.
